# Bank Soal UAS UT: Basis Data (MSIM4206)

Aplikasi latihan soal satu halaman (`index.html`) untuk persiapan UAS Semester 2, S1 Sistem Informasi, Universitas Terbuka.

- 3 set, 30 soal: Modul 1 Tes Formatif 1 (foto buku hlm. 1.16-1.17) dan dua set kuis dari screenshot.
- Teks soal disalin persis dari sumber, dengan foto atau screenshot asli di setiap soal.
- Pembahasan tiap pilihan muncul setelah menjawab. Pembahasan adalah analisis, bukan kunci resmi buku.
- Kunci buku bisa diisi di tab "Kunci & hasil". Jawaban dan kunci tersimpan di browser (localStorage).

## Cara pakai
Buka `index.html` di browser. Tidak perlu instalasi atau server.

## Menayangkan lewat GitHub Pages
1. Settings > Pages > Source: Deploy from a branch > `main` / `(root)`.
2. Buka alamat yang diberikan GitHub Pages.

## Catatan
Repo ini memuat foto halaman buku Penerbit Universitas Terbuka. Gunakan repo **private** untuk pemakaian pribadi. GitHub Pages untuk repo private membutuhkan paket berbayar.
